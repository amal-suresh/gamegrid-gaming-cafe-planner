# 🎮 GAMEGRID — Gaming Café Planner

A React-based calculator to plan and estimate the profitability of a PS5 gaming café.

## Features
- PS5 revenue and utilisation calculations
- Add-on income: snacks, carrom, pool, and RC cars
- Monthly expense management
- Initial investment planning
- Maintenance and equipment replacement reserves
- Operating profit, monthly cash flow, and investment payback
- Responsive gaming-themed UI

## Tech Stack
- React
- JavaScript
- CSS
- Vite

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Note
Calculations are estimates for business planning. Data is currently stored in React state and resets when the page is refreshed.
